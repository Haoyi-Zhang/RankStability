# Same-information decision and phase-local work

The four JSON files retain all original input cases/metadata, the bounded
outcomes/certificates, their summary, and exact interpreter/source/input bindings.
No new matrix or native observation was generated. All 273 compared statuses
and global minima agree with record-free direct enumeration over 6,625,406 masks.
The two forty-mutant fixtures are excluded by the fixed fifteen-mutant cap.
Time-10 historical queries remain historical; current real-source public
results are separate under `evidence/public-source-correction/`.

Producer and interval flow counters are phase-local. Partial checker steps,
flow calls and direct mask visits have different units and cannot be divided
into a speedup claim. Direct enumeration answers the same status/minimum query
but does not supply the portable cut packet. Parameter variants, paired controls
and profiles do not establish independently acquired time-ordered histories.
